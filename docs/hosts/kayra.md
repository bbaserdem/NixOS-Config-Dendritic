# Kayra

_Kayra; messenger of Tengri, personified by a gray wolf._

**Kayra** is a live NixOS system, with `x86_64` architecture.

## Plans

The future plans for this host is;

- Split into two actual _nixos_ outputs; `kayra-arm` and `kayra-amd`.
- One shared module `kayra` that does not define the architecture.
- One drive, two OS's (dual-boot).
- Actual OS on physical drive
